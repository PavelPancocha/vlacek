# D-020: Skryté vývojářské volby v pauze

Datum: 2026-10-12. Stav: přijato.

## Kontext

Na tabletu a v Tesle se parametry adresy zadávají obtížně. Diagnostika a opakovatelný svět jsou nástroje dospělého: [dokument 04 §11](../../vlacek-predavaci-balicek/04_PROCEDURALNI_SVET.md) je vylučuje z dětského menu a [UI-07](../../vlacek-predavaci-balicek/11_TESTY_A_AKCEPTACE.md) vyžaduje rodičovskou branku. Uložená kvalita a omezené efekty už patří do save, ale kvalita dosud neměla ovládání.

## Rozhodnutí

1. **Branka.** V pauze otevře vývojářské volby pět aktivací malé řádky `Build …` během jednoho okna 3 sekund. Pomalejší aktivace zahájí nové okno; po otevření a při opuštění pauzy se počítadlo resetuje. Řádka má dosavadní vzhled, pouze je skutečným tlačítkem. Myš, dotyk, Enter i mezerník používají stejný router. Nejde o zabezpečení proti dospělému, ale o oddělení od běžné dětské cesty. Nová viditelná položka se nepřidává.
2. **Volby.** Český panel nabízí Diagnostika (Vypnuto / Zapnuto), Vykreslování (Auto = WebGL s Canvas fallbackem / Canvas), Kvalita (Auto / Standard / Nízká), Omezené efekty (Vypnuto / Zapnuto) a Číslo světa. Prázdné číslo znamená náhodný nový svět; jinak musí jít o desetinné celé číslo 0–4294967295. Číslo ovlivňuje nové cesty, nikoli obnovu již uložené cesty. Pole a akce mají nejméně 64 CSS px, na malém displeji se pole posouvají. Otevřený panel zůstává přístupný i po otočení na výšku, rozpracované hodnoty se neztrácejí a hra dál zůstává v pauze. Fokus po otevření přejde na Diagnostiku, po zavření na řádku Build. Panel skrývá svět jako neprůhledná obrazovka podle společného rozhodnutí D-006 i po otočení nebo neúspěšném použití voleb; zavření vrací průsvitnou pauzu bez změny `PAUSED` a clona se odstraní až po `POST_RENDER` čerstvě vykresleného světa ve standardním i nízkém profilu.
3. **Úložiště a priorita.** Platformní vlastník `DevOptions` čte při startu jednou klíč `vlacek.dev.v1`: JSON s `debug` (boolean), `renderer` (`auto` / `canvas`) a volitelným `seed` (číslo). Klíč není součástí save ani jeho zálohy. Chybějící, neplatný nebo nedostupný obsah dává výchozí hodnoty; jednotlivá chybná pole se ignorují. Kvalita a omezené efekty zůstávají v existujících `settings.quality` a `settings.reducedEffects` a mění se přes session a její běžnou cestu ukládání. Formát save, katalog i generátor se nemění.
4. **Adresa má přednost.** Platný parametr vyhrává nad uloženou volbou, pak platí výchozí hodnota. Diagnostika rozumí `?debug=1` i explicitnímu vypnutí `?debug=0`; renderer `?renderer=canvas|auto`; kvalita `?quality=auto|standard|low`; svět `?seed=N`. Neplatný parametr se ignoruje a použije se uložená volba. Kvalita z adresy sama nikdy nepřepisuje save. Auto zatím odpovídá standardnímu profilu; nízký profil má DPR nejvýš 1, limit 30 FPS a omezené efekty. Diagnostika `renderProfile` uvádí efektivní kvalitu a vyřešené DPR, FPS a efekty.
5. **Použití přes reload.** Panel začíná efektivními volbami, úpravy jsou pouze rozpracované. „Použít a znovu načíst“ předá dvě save nastavení session a zavolá `session.interrupt()` (vymaže vstupy, flushne editace a uloží cestu). Výsledek vrací stávající cesta ukládání; druhý zápis save nevzniká. Teprve po potvrzení úspěšného primárního zápisu (`saved`) se zapíše dev klíč a při úspěchu načte stejná stránka bez všech výskytů `debug`, `renderer`, `quality` a `seed`. Ostatní parametry, cesta nasazení a fragment zůstávají. Reload se provede i u adresy s fragmentem, která žádné dev parametry neměla. Renderer i profil se vybírají při startu; stejná pravidla platí pro diagnostiku a seed. „Výchozí“ nastaví kvalitu Auto a vypne omezené efekty stejnou cestou; dev klíč odstraní až po úspěšném uložení session. „Zavřít“ zahodí dosud nepoužité rozpracované úpravy bez zápisu a vrátí pauzu.
6. **Připomínka.** Pokud jsou efektivně zapnuté diagnostika, Canvas, pevný seed, kvalita jiná než Auto nebo omezené efekty, řádka pauzy je `Build <id> · dev`. Explicitní výchozí hodnoty bez aktivní dev volby marker nepřidávají.

## Důsledky a kompatibilita

Vývojářské volby nemění herní ovládání, fyziku ani rozehranou trasu. Uložená cesta se po reloadu obnovuje běžnou potvrzovací cestou; svět z panelu se projeví až při novém výjezdu. Výchozí volby nemažou cestu ani soupravu. Neplatné číslo panel odmítne bez reloadu. Při neúspěšném uložení session (režim pouze v paměti, ochrana novějšího save, nedostupné či plné úložiště nebo příliš velký save) se stránka znovu nenačte a dev klíč se vůbec nemění. Panel zůstane otevřený, zachová zadaná pole a vysvětlí, že hra nyní nemůže uložit cestu a nastavení a že je třeba zůstat na této stránce. Dvě save nastavení už jsou v živé session; při neúspěchu zůstávají v paměti. Pokud až následný zápis dev klíče selže, cesta a dvě nastavení jsou uložené, ale dev klíč zůstává původní a reload se opět neprovede; panel přesně popíše tento stav. Dev klíč a save nejsou transakce, pořadí zápisů chrání rozpracovanou cestu. Pro běžný save nadále platí stávající režim pouze v paměti a ochrana novějšího save podle dokumentu 08.

Unit testy pokrývají parsování, prioritu, chybující storage, celé okno branky a model formuláře; integrace obnovu nastavení a cesty po `interrupt()`. `tests/e2e/quality.spec.ts` ověřuje dočasný parametr a uloženou kvalitu; `tests/e2e/dev-menu.spec.ts` dětskou cestu, myš/dotyk, klávesnici a fokus, reload, reset, selhání ukládání bez ztráty cesty, prioritu adresy, validaci světa, omezené efekty a cíle na 568 × 320 a dostupnost otevřeného panelu po otočení v obou projektech. Otevírací sekvence používají reálné vstupy Playwrightu a hodiny `page.clock` zastavené pouze během pěti aktivací; běžící smyčka se následně obnoví a test ověří postup simulačního ticku. Samostatný test posune hodiny o 3001 ms a ověří vypršení okna. Produkční okno 3 s, timeouty a počet opakování testů se nemění. Fyzický Android tablet a Tesla včetně konkrétního firmware jsou **NEOVĚŘENO**; automatické Chromium testy nejsou důkazem výkonu zařízení.
