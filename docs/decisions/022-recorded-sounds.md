# D-022 — Nahrané zvuky

Datum: 2026-10-13. Stav: implementováno; poslech a fyzická zařízení **NEOVĚŘENO**.

## Důvod a rozhodnutí

Syntetizované tóny nahrazují lokální nahrávky skutečných strojů, zvířat, prostředí a fyzických zvonků. Katalogových deset `hornAudio` ID, save ani generátor se nemění. Doména neimportuje audio. Jediný `AudioManager` vlastní kontext, dekódované buffery, uzly a omezení hlasů; `AudioDirector` čte veřejný stav simulace jednou za aplikační frame.

Preferujeme CC0 1.0 / public domain. Dva klipy BEDIA používají CC BY 4.0 s úplnou atribucí a oznámením změn; NC, ND a SA se nepoužívají. Kompletní zdrojové adresy, autoři, licence, SHA-256 původních bajtů a časové výřezy jsou v [sources.json](../../scripts/audio/sources.json). Freesound soubory jsou původní stažené HQ MP3 preview, nikoli bezztrátové originály. Originály (přes 100 MiB) nejsou součástí repozitáře.

Atribuce je součástí publikovaného buildu: [credits.txt](../../assets/audio/credits.txt), dosažitelný odkazem **O zvucích — autoři a licence** v sekci Zvuky skrytých vývojářských voleb. Vite publikuje fingerprintovaný textový soubor na stejném originu; odkaz jej otevře v novém panelu. Obsah všech 32 řádků zdrojů (autoři včetně recordistů, názvy, zdrojové a licenční URL, změny a hashe) generuje [credits.ts](../../scripts/audio/credits.ts) ze stejného `sources.json`. Unit test vyžaduje přesnou shodu dodaného textu s generovaným obsahem i úplný kredit každého CC BY klipu; E2E ověřuje odkaz a text z produkčního serveru.

## Reprodukce a formát

Použito FFmpeg **6.1.1-3ubuntu5**, `libmp3lame`, 44 100 Hz, mono, VBR `-q:a 5`, bez převzatých metadat. MP3 volíme pro `decodeAudioData` v Chromium, Firefoxu a Safari; test přehrávání a dekódování proběhl v Playwright Chromium. Firefox, Safari, fyzický Android a Tesla **NEOVĚŘENO**.

FFmpeg musí být v `PATH`; ověření `ffmpeg -version`. Pro Ubuntu 24.04 odpovídá použitý systémový balík verzi `7:6.1.1-3ubuntu5` (`sudo apt-get install ffmpeg=7:6.1.1-3ubuntu5`). Jiné systémy použijí distribuci FFmpeg 6.1.1 s libmp3lame z [oficiálního rozcestníku](https://ffmpeg.org/download.html). Lokální export proběhl s již nainstalovaným balíkem; jeho nová instalace na čistém stroji je NEOVĚŘENO. Běžný build/unit testy FFmpeg nepotřebují, CI export neprovádí.

```bash
volta run node scripts/audio/process-audio.ts /cesta/k/originalum
volta run node scripts/audio/credits.ts
volta run node scripts/audio/verify-audio.ts
volta run node scripts/audio/contact-sheet.ts /cesta/k/vystupu
VITEST_MAX_WORKERS=4 volta run npm test -- tests/unit/content/soundManifest.test.ts tests/unit/platform/AudioManager.test.ts tests/unit/platform/AudioDirector.test.ts tests/unit/platform/VoiceBudget.test.ts
```

Znovustažení: stáhnout adresu `download` každého unikátního `original` v JSON do předaného adresáře (`curl --fail --location 'ADRESA' --output '/cesta/k/originalum/ORIGINAL'`). Zpracování odmítne chybějící nebo jinak hashovaný soubor. Veřejné CDN může později vracet 403; nelze potichu zaměnit bajty za jinou verzi. Přesný filtr i argumenty FFmpeg vlastní [process-audio.ts](../../scripts/audio/process-audio.ts), žádný skrytý ruční export.

Filtr: výřez `atrim` → vynulování času → mono → high-pass 70 Hz → low-pass 6 kHz → `loudnorm` (one-shot −18 LUFS, smyčky −28 LUFS, true peak −6 dBTP, LRA 7) → 44,1 kHz → limiter 0,5 bez automatického zesílení. Krátké zvuky mají 25 ms náběh i doběh (nejvýše osmina délky). Smyčky mají lineární crossfade konce a začátku 30 ms až 2 s podle JSON, přesunutý dovnitř cyklu. Crossfade míchá fade-out konce a fade-in začátku pomocí `amix`; cyklický spoj má navíc 10 ms měkké hrany. Časování výřezů používá celé PCM vzorky po normalizaci do dočasného WAV. Ten se vždy odstraní, včetně selhání exportu. Před a za cyklem je 120 ms stejného sousedního zvuku; manifest přehrává pouze `loopStartSec=0.12` až `loopEndSec=0.12 + výřez − crossfade`. LAME zapisuje gapless informace; explicitní body nepřehrávají okraje MP3. `verify-audio.ts` dekóduje dodané MP3, ověří hranice, krok ve spoji (<0,025 plné amplitudy), vrchol (≤0,54 po ztrátovém kódování) a celkový rozpočet 3 MiB. Tato numerická kontrola není důkazem neslyšitelného spoje ani zvukové kvality.

Dodáno **32 MP3, 1 926 913 bajtů (1,84 MiB)**. Reprodukce se stejným FFmpeg vytváří stejné bajty; jiné verze enkodéru mohou mít jiné hashe výstupu.

Export nahrávek obnoví i `credits.txt`. Samostatný příkaz `volta run node scripts/audio/credits.ts` obnoví pouze kredity po změně provenience; nevyžaduje FFmpeg ani originály.

## Načítání, vrstvy a životní cyklus

Vite do JS vloží pouze fingerprintované URL (`?url&no-inline`), žádný klip do inline data URI. PWA precache po prvním snímku stahuje MP3 soubory na pozadí spolu se zbytkem buildu pro offline hraní, i při vypnutých zvucích a bez gesta. Samotný AudioManager před prvním gestem nic nestahuje ani nezakládá AudioContext; zvuk dekóduje až na vyžádání. Při opakované návštěvě s aktivním service workerem a zachovaným úplným balíkem se soubory čtou z cache ([D-031](031-installable-offline-pwa.md)). Buffery se sdílejí podle souboru. Vypnuté zvuky v AudioManageru nezakládají kontext, nestahují ani nezačínají dekódování; vypnutí během fetch zruší navazující práci. Již zahájené `decodeAudioData` nelze přerušit, jeho pozdní výsledek však nepřehraje zvuk. Pauza, skrytí stránky a ztráta fokusu zastaví hlasy a suspendují kontext. Další gesto je jediná cesta k resume. Dispose odpojí uzly, uzavře kontext a uvolní buffery. Fetch/decode/context chyby ponechají hru hratelnou tiše a objeví se v diagnostice `audioDetails.failures`; neúspěšný soubor se během načtení stránky neopakuje každý frame.

Čekající přehrání je omezeno na jednu operaci na klíč vrstvy; další framy pouze přepisují požadovaný stav. Po dokončení fetch/decode se použije poslední ID, gain, rate, priorita a pulsed stav. Změněné ID nebo nové explicitní resume se po dokončení starého požadavku znovu vyhodnotí jednou, bez fronty starých framů. `audioDetails.pendingLayers` udává počet těchto operací. Suspend/mute zahodí požadované vrstvy a invaliduje playback; dispose navíc abortuje všechny vlastněné fetch požadavky přes `AbortController`. Probíhající decode může doběhnout, ale po dispose nevytvoří hlas ani cache a čekající operace se uvolní. Očekávaný abort při dispose není diagnostická chyba nahrávky.

Zvířecí reakce, pop a dřevěné ťuknutí musí začít nejpozději **250 ms** po požadavku podle času běžícího AudioContextu; zpožděná reakce se tiše zahodí, i když hra dál jede. Načtený buffer zůstává v cache pro další čerstvou reakci. Pauza je vždy invaliduje epochou. Píšťaly limit nemají: odpovídají explicitnímu houkání a mají vyšší prioritu, jejich první načtení nemá ztratit funkční odezvu. Vývojářský poslech má explicitně neomezenou platnost, aby šlo na tabletu poslechnout i pomalu načtenou nahrávku; Zavřít, Zastavit nebo přerušení jej stále zruší.

- **Kola:** tiché klapání, gain i rate rostou s rychlostí až do konfigurovaného maxima, při nule žádná hlasová smyčka.
- **Pára:** čtyři takty na otáčku hnacího kola z ujeté délky, silnější při `THROTTLE`; maximálně dva krátké bufferové uzly s měkkou 15 ms obálkou v jednom plánovaném loop hlasu, bez fronty doháněných taktů.
- **Diesel:** BEDIA idle při ≤20 u/s, running nad touto mezí; gain i rate reagují na rychlost. Je to důlní lokomotiva, nikoli potvrzený český posunovač nebo čistě izolovaný hlavní motor.
- **Elektřina:** Queensland ICE idle hum s rychlostním gain/rate. Po opakování 403 pro [Elron horn](https://freesound.org/people/Islabonita/sounds/471063/) a [EMU traction](https://freesound.org/people/JotrainG/sounds/647669/) a průzkumu Commons/OpenGameArt nebyl získán vyhovující evropský elektrický klip. Elektrické píšťaly používají přiznaný skutečný dieselový horn s rate 0,9 / 1,15 / 0,75. Nejde o tvrzení o české řadě ani o naměřený trakční rozjezd.
- **Pohádkové:** tři rozdílné fyzické chimes/glockenspiel, bez dalšího engine bedu.
- **Píšťaly:** picker, hráč i NPC používají stejný katalogový klip. NPC odpověď je slabší se vzdáleností; hráč má vyšší prioritu.
- **Přejezd:** jeden belgický výstražný zvonek v `WARNING`, `CLOSING`, `CLOSED`, vzdálenost od horizontálního středu pohledu určuje gain. V `OPENING` i `OPEN` ztichne. Centrum pohledu počítá stávající `frameLeftX`; žádná změna automatu.
- **Tunel:** překrytí hlavních intervalů `tunnelSite` s rozsahem celé soupravy určuje `setCovered(fraction)`; engine a kola mají plynulý low-pass až 1,1 kHz a krátké 90 ms echo (12 %). Píšťaly, zvířata a výstrahy zůstávají čisté. Integrátor může nahradit výpočet hodnotou krytí z tunnel lane bez změny audio kontraktu.
- **Prostředí:** `ambientSound(biome, season?)` je jediný přepínač pro world-core: venkov/podhůří ptáci, les lesní ptáci, voda potok, pobřeží moře, hory/zima vítr; letní venkov cvrčci. Současné napojení má pouze biom, tedy sezónní cvrčci se v jízdě aktivují až po dodání sezóny (v poslechovém menu již jsou). Město vynecháno, protože zdroj neprošel kontrolou absence řeči. Přechod bedů trvá přibližně 2 s; druhý bed se vejde jen při volném loop hlasu.
- **Reakce:** všech 12 `AnimalKind` má mapování; osm domácích/vodních druhů vlastní hlas, deer/fox/squirrel/hedgehog tiché listí ve větru. Horse/songbird jsou připravené k poslechu, současný katalog je neumisťuje. Bublina je nahraná ústní foley, plná souprava jeden dřevěný úder.

Celkový limit **8 hlasů: ≤3 loop, ≤5 one-shot** kontroluje stávající `VoiceBudget`. Plánovaný parní engine spotřebuje jeden loop hlas. Priorita: hráč horn / UI 100, bell 90, NPC horn 80, engine 70, kola 60, zvíře 40, ambient 10. Při plném loop rozpočtu má výstraha přednost před prostředím; crossfade se zkrátí, pokud funkční vrstva potřebuje jeho hlas. Stejný zvířecí klip se hlasitostně nestohuje. Omezené efekty zvukové funkce nemění.

## Poslech a akceptace

Skryté vývojářské volby D-020 obsahují rozbalovací seznam **Zvuky**, tlačítko pro každé manifest ID a **Zastavit**. Nový poslech nejdříve ukončí předchozí klip a jeho čekající požadavky bez suspendování kontextu, takže se nahrávky v seznamu nepřekrývají a opožděné dokončení suspendu nezmrazí nový klip. Je dosažitelný myší, dotykem i klávesnicí přes stejný InputRouter, respektuje nastavení Zvuky. V pauze tento explicitní poslech odemkne kontext pouze gestem; Zastavit, Zavřít a přerušení jej znovu suspendují. Save ani generátor se nemění.

Kontaktní list a jednotlivé waveform/spektrogram PNG byly vytvořeny mimo repozitář: `/home/pavel/Projects/vlacek-worktrees/_runs/shots/audio/contact-sheet.png`. Vizuálně jsou průběhy konzistentní s popisem zdrojů, bez zjevného flatteningu dodaných špiček; některé originály dosahovaly 0 dBFS, což útlum nemůže zpětně opravit; vysoké chime/bird harmoniky se tlumí filtrem a gainem. Spektrogram **nepotvrzuje nepřítomnost řeči/hudby**, příjemnost ani dětskou hlasitost. Obojí, slyšitelnost spojů, kalibrace tabletu, fyzický Android, Safari/Firefox a konkrétní Tesla/firmware zůstávají **NEOVĚŘENO** do potvrzení vlastníkem.
